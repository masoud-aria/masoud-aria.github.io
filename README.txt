راهنمای قالب جدید سایت مسعود آریا

این نسخه یک قالب استاتیک مناسب GitHub Pages است و شامل:
- صفحه اصلی
- ۷ صفحه محتوایی: اشعار، مقاله، داستان، نقد، عکس، موزیک، فیلم
- صفحه بیوگرافی
- طراحی شیشه‌ای با تم یشمی
- انیمیشن فشار + شکست شیشه‌ای برای دکمه‌ها
- افکت لمس کوچک برای عناصر قابل کلیک
- سه دکمه اجتماعی در پایین صفحه اصلی: واتساپ، تلگرام، اینستاگرام
- واکنش‌گرا برای موبایل و دسکتاپ
- عکس پروفایل در assets/profile.jpg

فایل‌ها:

poems.html
articles.html
stories.html
criticism.html

assets/profile.jpg

سه موردی که قبل از انتشار باید تنظیم شوند:
1) لینک واتساپ، تلگرام و اینستاگرام در index.html
2) متن واقعی هر صفحه
3) اگر فونت فعلی سایت متفاوت است، فقط بخش font-family در style.css را به فونت قبلی برگردانید.

نکته:
آیکون‌ها از Font Awesome CDN استفاده می‌کنند. بنابراین هنگام مشاهده آنلاین باید اینترنت در دسترس باشد.
